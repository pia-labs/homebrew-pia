# Homebrew Tap for PIA

Official Homebrew Tap for [PIA (Programmable Intelligence Agent)](https://github.com/pia-labs/pia) — a fast, lightweight native terminal coding agent built with pure Rust.

## Installation

```bash
brew tap pia-labs/pia
brew install pia
```

Or install directly in a single command:

```bash
brew install pia-labs/pia/pia
```

## Update

```bash
brew update
brew upgrade pia
```

## Verification

```bash
pia --version
```
